# 弱电工程管理平台 用户服务协议（V1.0）

**生效日期：2026-09-19**

欢迎使用弱电工程管理平台（以下简称"本平台"）。在注册、登录及使用本平台服务前，请您务必仔细阅读并充分理解本协议全部条款。

## 一、协议范围

1.1 本协议是您与本平台运营方之间关于使用本平台各项服务所订立的协议。
1.2 本平台服务包括：工程信息发布、投标撮合、合同见证与签订、资金代管与结算、施工过程记录、纠纷仲裁辅助等。

## 二、账号与实名

2.1 您应使用真实、准确的身份信息完成实名认证，并对账号下全部行为承担责任。
2.2 您的账号仅限本人使用，不得出借、出租、转让。
2.3 平台有权对身份存疑的账号采取限制交易、冻结资金、暂停服务等措施。

## 三、工程交易规则

3.1 甲方应真实描述工程需求，及时处理投标并按约支付工程款。
3.2 乙方应具备承接相应工程所需的资质与能力，按约施工并保证质量。
3.3 工程款结算须经平台：平台收取成交金额一定比例的服务费（以平台设置为准），并按约留存质保金。
3.4 双方应在平台内留存施工日志、现场打卡、照片、验收单等过程记录，作为纠纷仲裁依据。

## 四、资金与结算

4.1 平台提供的资金代管不构成金融机构支付业务，充值与提现通过合作支付渠道完成。
4.2 提现须经平台审核；存在纠纷、风控异常或资料不全的，平台有权暂缓打款。
4.3 质保金在质保期满且无未决质保工单后释放给乙方。

## 五、纠纷处理

5.1 双方发生争议的，可向平台提交纠纷工单，平台将基于平台内记录进行调解与仲裁。
5.2 对平台处理结果不服的，可依法向有管辖权的人民法院提起诉讼。

## 六、免责与责任限制

6.1 平台是信息撮合与过程见证方，不是任何工程项目的实施主体。
6.2 因不可抗力、系统维护等导致的暂时性服务中断，平台不承担责任。
6.3 您因违反本协议给平台或第三方造成损失的，应承担赔偿责任。

## 七、其他

7.1 本协议适用中华人民共和国法律。
7.2 平台有权对本协议进行修订并公告，修订后的协议自公告之日起生效。
